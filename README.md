# Min Ekonom Light

Testversion av Min Ekonom för barn och unga under 18, utan bankkoppling. PWA byggd med React, Vite och Tailwind.

- Utveckla: `npm install && npm run dev`
- Bygg: `npm run build` (publiceras från `dist`)
- Demo-data: öppna med `?demo=1`. Rensa allt: `?reset=1`
- All data sparas lokalt i enheten. Skärmdumpsavläsningen är fejkad i den här versionen.
